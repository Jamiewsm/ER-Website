# Korean Test Copy Guide

진단 문항과 결과지의 한국어 카피 작성/검토 가이드입니다. 영어 학술 개념을 한국어 일상 장면으로 번역하는 30 패턴 + 27 subtype 시드 단어 + 금기 표현 + before-after 예시 10개.

## 핵심 원칙

1. **표면 행동이 아닌 동기를 묻는다.** "친절한가요" 가 아니라 "친절을 표현할 때, 그 밑에 어떤 욕구가 가장 강한가요" 식.
2. **일상 장면으로 번역한다.** "결정 직전", "갈등 기류", "도움을 요청할 때" 등 사용자가 즉시 떠올릴 수 있는 장면으로.
3. **낙인/결정론을 피한다.** "당신은 ~형입니다" 보다 "현재 응답은 ~형 가까이". "원래 그래" 보다 "지금 자동 반응이 ~".
4. **종교 중립.** ER 이 기독교 코칭이지만 진단 문항은 종교 색채 없이.
5. **CLAUDE.md 의 콜론 끝 X 규칙 준수.** 한국어 문장 끝에 `:` 대신 `.` 사용.

## 3. 금기 표현

진단 문항 + 결과지에서 사용하면 안 되는 표현 + 이유 + 대체.

| 금기 | 이유 | 대체 |
|---|---|---|
| "당신은 ~형입니다" (확정 단언) | 낙인/결정론, 자율성 침해 | "현재 응답은 ~형 가까이", "지금 자동 반응이 ~" |
| "건강한 N형 / 안 건강한 N형" | 건강 등급 도덕화, 자기 비난 유발 | "통합 방향 / 비통합 방향", "자질이 살아있을 때 / 압박 시" |
| "원래 그래" / "타고난 거야" | 변화 가능성 부정, 결정론 | "지금까지의 자동 반응이 ~", "현재 패턴이 ~" |
| 종교/영성 단정 ("죄성", "본성의 죄") | ER 진단지는 종교 중립. 기독교 코칭은 별도 트랙 | 가치 중립적 표현, 동기/패턴 묘사 |
| "당신의 단점/장점은 ~" | 도덕적 평가, 자기 비난/방어 유발 | "이 type 의 자동 반응이 향하는 곳/피하는 곳" |
| 성별/연령 가정 ("남자라면", "30대는") | 다양성 침해 | 일반 표현, 상황 중립 |
| 비교/우열 표현 ("더 우수한", "약한 type") | type 간 우열 부재가 에니어그램 핵심 원칙 | "다른 표현 양식", "다른 자동 반응" |
| 감정 진단 ("화내지 마세요", "감정적이지 않게") | 감정 부정 = 잘못된 코칭 신호 | "그 감정의 출처를 살펴보세요" |
| "꼭 ~해야 합니다" | 의무 부과 — Type 1 트리거 | "~이 도움이 될 수 있습니다", 선택권 보존 |
| 콜론 끝 ("다음과 같습니다:") | CLAUDE.md rule #5 | 마침표 끝 ("다음과 같습니다.") |

## 4. Before-After 10 예시

진단 문항의 나쁜→좋은 변환. 각 예시는 (a) 표면 행동을 묻는 나쁜 문항 (b) 동기/방어/회피를 묻는 좋은 문항 (c) 변환 이유.

### 1. Type 1 핵심

- before — "당신은 분노가 많은 사람입니까."
- after — "어떤 일이 잘못됐다고 느낄 때 답답함이 빠르게 올라오는 편이다."
- 이유 — (1) 낙인 제거 (2) 동기 (옳음 기준) 표현 (3) 일상 장면.

### 2. Type 2 비대칭 욕구

- before — "사람들을 도와주는 것을 좋아합니까."
- after — "사람의 필요를 빠르게 읽고 먼저 채워 주려 하지만, 내가 도와달라고 말하는 건 어색하다."
- 이유 — Type 2 의 핵심은 비대칭 (받는 것의 어색함). 이걸 직접 묻는다.

### 3. Type 3 정체성=성과

- before — "당신은 야망이 큰가요."
- after — "내가 가진 게 아니라 내가 만든 결과로 가치가 정해진다고 느낄 때가 있다."
- 이유 — 야망/이미지 표면이 아니라 vanity (정체성 = 성과) 의 motivation 직접 질문.

### 4. Type 4 결핍 정체성

- before — "당신은 우울한 편입니까."
- after — "겉으로 함께 있어도 나만 완전히 이해받지 못한다는 정서적 거리감을 자주 느낀다."
- 이유 — 우울 = 증상. envy/longing = 패턴. 패턴을 묻는다.

### 5. Type 5 침범 회피

- before — "혼자 있는 것을 좋아합니까."
- after — "예고 없는 감정 요구나 갑작스러운 침범이 들어오면, 즉시 에너지를 닫고 물러나는 반응이 자동으로 나온다."
- 이유 — 혼자 = 표면. avarice/isolation = 동기. 동기를 묻는다.

### 6. Type 6 검증 강도

- before — "당신은 걱정이 많은가요."
- after — "중요한 결정 전, 겉으로 드러난 정보보다 숨어 있는 의도와 잠재적 리스크를 먼저 확인해야 안심이 된다."
- 이유 — 걱정 일반화 X. fear/projection 의 구체 표현 (검증/대비).

### 7. Type 7 가능성 회피

- before — "당신은 긍정적인가요."
- after — "불편한 현실이나 무거운 감정에 오래 머물면 에너지가 떨어져, 분위기를 바꾸거나 다른 가능성으로 주의를 전환하려는 패턴이 있다."
- 이유 — 긍정 = 표면. gluttony/rationalization = 동기 (도피).

### 8. Type 8 통제 추구

- before — "당신은 강한 사람입니까."
- after — "내 영향력이 무시되거나 함부로 통제되는 상황에서는 즉시 주도권을 회수하려는 반응이 먼저 나온다."
- 이유 — 강함 = 자기 진단 부정확. lust/denial 의 구체 표현 (통제 회수).

### 9. Type 9 자기 흐림

- before — "당신은 평화로운가요."
- after — "관계나 환경과의 연결이 끊기는 상황을 크게 불편해해서, 갈등을 키우지 않으려고 내 실제 욕구나 우선순위를 뒤로 미루는 선택을 자주 한다."
- 이유 — 평화 = 표면. sloth/dissociation = 동기 (자기 흐림).

### 10. Wing 활성도 (예 — 7w8 vs 7w6)

- before — "당신은 8번 같나요 6번 같나요."
- after — "새로운 일을 추진할 때, 제약이 보여도 강하게 밀어붙이며 방해가 생기면 정면으로 돌파하는 편이다 (A) / 가까운 관계의 안정과 안전망이 흔들리지 않는지 먼저 점검해야 마음이 놓이는 편이다 (B)."
- 이유 — type 비교 X (사용자가 type 모름). wing 시그니처를 직접 묻는다.

## 5. 결과지 카피 가이드 (Phase 5 에서 활용)

결과지 작성 시 추가 원칙.

- **이중 표현** — 자질 (살아있을 때) + 패턴 (압박 시) 양면을 함께 보여줌. 한 면만 X.
- **성장 방향** — Vice → Virtue 변환을 도덕적 의무가 아닌 자질 회복으로 표현 (예 — "분노 통제하기" X, "분노 안에서 평온 회복하기" O).
- **본능 stack 빈자리** — 3차 (blind) 본능을 비난 X, 발달 영역으로 표현.
- **윙 차이** — 윙 % 가 약/중/강 인지 표시 (예 — `7w8(50%) — 중간 강도`).
- **arrow** — 통합/비통합 화살표를 자기 비난 도구 X, 자기 이해 도구 O.
