# Language Layers

## Goal

ER의 복음적 세계관은 유지하되, 기본 결과지는 일반 사용자도 부담 없이 읽을 수 있어야 합니다.

## Three Layers

| Layer | Where | Tone |
|---|---|---|
| General | 기본 결과지 본문 | 회복, 진실, 내면의 방향, 오래된 믿음, 현재에 머무는 힘 |
| Spiritual | 심화 회복 문단 | 더 깊은 사랑, 붙들림, 은혜와 의미 |
| Faith optional | 선택 문장/기도 | 주님, 기도, 신앙이 있는 분이라면 |

## Term Translation

| Church-facing term | Default report term |
|---|---|
| 복음 안에서의 회복 | 깊은 회복의 방향 |
| 죄 / 거짓 자아 | 나를 묶어온 오래된 믿음 |
| 회개 | 방향을 바꾸는 연습 |
| 진리 | 새롭게 붙들어야 할 진실 |
| 기도문 | 머무름의 문장 |
| 하나님 안에서 | 더 깊은 사랑과 안정감 안에서 |

## Rules

- 기본 필드에는 `복음`, `죄`, `회개`, `거짓 자아`를 직접 쓰지 않습니다.
- `faith_optional`에는 신앙 언어를 쓸 수 있습니다.
- 기본 본문은 진단/분류보다 회복과 삶의 적용을 먼저 느끼게 합니다.
- 사용자를 단정하지 않고 가능성 언어를 씁니다: `~일 수 있습니다`, `~하기 쉽습니다`, `~로 나타날 수 있습니다`.
- 오탈자와 어색한 번역을 금지합니다. 특히 `격과지`, `길이 다루며`, 맥락 없는 `인정을 쫓는` 표현을 사용하지 않습니다.
