# 내러티브 테스트 이름·영어 결과·검사 검토 계획

2026-10-13 사용자 요청. 현재 운영 경로 `test.html → js/test.js`를 유지한다.

1. `test` 트랙에서 검사 브랜드를 내러티브 테스트 / Narrative Test로 변경하고, 영어 상세 결과·미확정 결과·저장/공유/인쇄와 영어 문항 동등성을 수정한다.

단어 청크는 글자 중간에서 나누지 않는다. `word-break: keep-all`, `overflow-wrap: normal`을 유지하며 의미 구문은 필요하면 전체 줄바꿈을 막는다. 기존 자료·untracked 산출물·채점 가중치는 임의로 변경하지 않는다.
