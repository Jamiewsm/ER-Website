# 2026년 10월 기본과정 — 결제·명칭 결정

## 공개 가격

| 구분 | 금액 |
|---|---:|
| 한국 직접 계좌이체 | ₩450,000 |
| 한국 신용카드·카카오페이·네이버페이 | ₩470,000 |
| 해외 PayPal·Zelle | $330 |

해외 가격은 2026년 8월 28일의 원·달러 환율 약 1,380원대를 참고해 ₩450,000의 환산액을 반올림한 고정 가격이다. 기수 도중 환율에 따라 매일 바꾸지 않는다.

## 결제 운영 단계

### 지금 가능한 방식

- 한국: 원화 계좌이체. 신청 접수 후 담당자가 계좌 정보를 안내한다.
- 해외: USD PayPal 또는 Zelle.
- 신청 폼은 결제 지역, 희망 수단, 카드사 할부 희망, 2회 분납 상담 요청을 함께 받는다.

### 국내 온라인 결제 권장안

국내 PG 한 곳을 웹사이트에 연결해 신용카드, 카카오페이, 네이버페이, 실시간 계좌이체를 한 결제창에서 제공한다. 개별 간편결제 API를 각각 계약·구현하는 것보다 계약, 승인, 환불, 정산을 한 곳에서 관리하기 쉽다.

우선 검토 사업자는 토스페이먼츠 결제위젯이다.

- 결제위젯: https://docs.tosspayments.com/guides/v2/payment-widget/integration-window
- 지원 결제수단 코드: https://docs.tosspayments.com/codes/enum-codes
- 카드 할부: https://docs.tosspayments.com/resources/glossary/card-installment

실제 오픈 전 필요한 것:

1. ER 사업자 명의 국내 PG 가맹점 신청·심사
2. 신용카드와 사용할 간편결제 수단 계약 확인
3. 운영 client key·secret key 발급
4. 테스트 결제, 승인 실패, 중복 승인, 취소·환불, 모바일 결제 검증
5. 결제 완료 webhook과 신청자 등록 상태 자동 연결

운영 키가 없을 때는 온라인 결제를 실제 가능한 것처럼 표시하지 않는다.

## 할부와 분납

- **카드 할부**: 국내 카드 결제가 열리면 결제창에서 카드사 정책에 따른 할부 개월을 선택한다. 가맹점은 한 번 결제받고 신청자가 카드사에 나누어 납부하는 방식이라 운영이 가장 단순하다.
- **ER 자체 분납**: 2회 주문, 납부 기한, 미납 처리, 중도 환불 기준을 따로 관리해야 한다. 우선은 신청 폼에서 상담 요청만 받고 개별 승인한다. 자동 분납은 결제·환불 상태표와 약관을 확정한 뒤 2단계로 구현한다.

## 공식 명칭

- 8주 과정: **에니어그램 기본과정**
- 전체 여정: **ER 전문가 과정** = 에니어그램 기본과정 + 팔로우업 스터디 + 1년 코칭스쿨
- 전문가 과정은 별도 기수 신청을 받지 않는다. 공개 신청 링크는 현재 모집 중인 에니어그램 기본과정에만 둔다.

## 자동메일 흐름

1. 신청자가 웹 폼을 제출한다.
2. `submit-application`이 보안 확인 후 신청서를 저장한다.
3. 관리자에게 새 신청 알림, 신청자에게 접수 확인 메일이 자동 발송된다.
4. 담당자가 코치 포털에서 신청자의 지역·결제 선호를 확인한다.
5. 담당자가 결제 안내 메일을 보내면 상태가 `payment_pending`으로 바뀐다.
6. 결제가 확인되면 `confirmed`로 변경하고 사전 성찰 설문 메일을 보낸다.
7. 수료 시에는 기본과정 수료 안내만 보내며 별도 전문가 기수 신청 링크를 넣지 않는다.
