## 설계 결정과 근거

### 결제 (Phase 1 — 7월 기수, 2026-06-11 확정)
- **USD 단일 가격** — $300 정가, 얼리버드 $270 (6/24까지 결제 완료). 원화 고정가 없음.

- 결제 안내는 사이트에 계좌/링크를 공개하지 않고 **신청 접수 후 등록 안내 메일로 발송**.
- **자리 확정 = 결제 완료 순** (선착순 10명).
- 세무: 현금영수증/면세 여부는 세무사 확인 필요 (보류).
