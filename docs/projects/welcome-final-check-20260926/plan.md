# 대표 명의 기본과정 웰컴메일 준비

발송 전 사용자가 검토할 메일을 실제 서버 템플릿과 같은 내용으로 준비한다. 수신 학생의 이름·과정·반·일정·제출 기한은 기존 DB 값을 사용하고, 새 학생용 교육포털 PDF로 연결한다.

1. welcome 본문과 서명을 손지영 대표 명의의 간결한 안내로 수정한다.
2. 기존 중복 발송 차단, 수신자 결정, 발신 설정과 미제출 알림은 유지한다.
3. 익명 A·B반 HTML/Markdown 미리보기를 실제 템플릿으로 생성한다.
4. 가상 메일 경계의 테스트로 본문·시간대 안내·기존 알림을 검증한다.

사용자 승인 전에는 메일을 보내지 않는다. 이 작업에서는 커밋·푸시·배포·운영 데이터 변경도 실행하지 않는다.
