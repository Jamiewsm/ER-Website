# 신청 안내 문구와 기존 관리자 결과 표시 정리

## 목적
기본과정 접수·결제 안내가 한 통으로 통합되고 등록 후 강의계획안·자기관찰보고서를 전달하는 백엔드 변경에 웹사이트 문구를 맞춘다.

## 범위
- site track만 변경한다. 신청 폼·완료 화면과 기존 관리자 신청 목록·메일 결과 표시를 수정한다.
- 기존 registration 및 pre_survey 이벤트와 정원 예약·등록 확정 RPC를 유지한다.
- 등록 준비 성공과 실제 메일 발송 성공·생략을 구분한다.
- 기존 등록 확정 후 운영자가 선택한 후속 발송은 유지하되, 백엔드가 지원하는 2026년 10월 기본과정에만 제공한다.

## 검증
가상 네트워크로 등록 준비·발송 생략·발송 실패·선택적 후속 발송을 검증하고 신청 렌더 및 기존 site 회귀 검사를 실행한다. 커밋까지만 수행하고 푸시·PR·머지·배포는 상위 작업에서 처리한다.
