## 검토 범위

실제 검사에서 쓰는 단어, 후보 선택, 상황과 동기 비교, 하위유형과 날개 질문, 결과 해석, 참고 자료 요약, 실험 참여 안내를 검토했다. 과거 검사 전용 문항과 연결된 외부 자료 본문은 포함하지 않는다.

## 주관식 제거

- 경험 기록과 실험 메모, 맞았던 부분, 틀렸던 부분, 상담에서 확인할 내용의 자유 입력을 제거했다.
- 상담에서 확인한 기본 유형·하위유형·날개는 선택 목록으로 바꿨다. 날개는 기본 유형의 양옆 유형만 고를 수 있다.
- 이름은 참가자 식별 정보로 유지한다.
- 주관식 내용은 이어하기, 결과지, 새 제출에 포함하지 않는다. 기존 서버 기록은 변경하지 않는다.
- 117개 응답을 81개 질문에 잘못 적용하지 않도록 세션 버전을 분리했다.
