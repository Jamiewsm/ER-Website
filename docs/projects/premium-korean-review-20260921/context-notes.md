# 맥락과 결정

- 사용자가 PR #150 배포 후 중복 단어 제거, 한국어 전반 재검토, 주관식 응답 제거를 요청했다.
- origin/main e90f2b7에 PR #150이 병합되어 있고 운영 검사에서 117개 단어 시작 화면을 확인했다. 배포 장부의 오래된 날짜를 현재 운영 증거로 사용하지 않는다.
- 동일 철자의 단어는 없지만 동의어·유사한 성격 묘사가 반복된다. 유형별 문항 수를 동일하게 유지하면서 9개씩 선별한다. 단어는 최종 유형 채점이 아닌 후보 선별에만 사용한다.
- 경험 기록과 실험 피드백의 주관식 문항을 제거한다. 참가자 이름은 식별 정보이므로 유지하고 결과 일치도/알고 있는 유형 등 선택형 피드백은 유지한다.
- 기존 서버 기록은 삭제하지 않는다. 새 검사 버전에서 구버전의 주관식 기록을 복원하거나 제출하지 않는다.
- 수정 목록은 사용자와 다음 검토자가 원문·수정문·이유를 비교할 수 있도록 남긴다. 기존 성격 유형 이론과 종교적 내용의 방향을 새로 확장하지 않는다.

- 단어·검사 세션·실험 분석 버전을 `word-narrative-v2`로 변경했다. 구버전 진행 기록은 새 질문에 적용하지 않는다.
- 기존 DB 컬럼은 유지하고 주관식 값은 새 제출에 null로 보낸다. 기존 호출 인자는 호환을 위해 남겨도 주관식 내용은 무시한다.
- 결과 제목에 내부 별칭인 특권 등이 나타나는 것을 브라우저에서 확인해 일반 한국어 본능 이름으로 정리했다.
- 한국어 조사 점검과 실제 화면 검토를 수행했다. 수정 목록은 원본과 최종 코드에 대응하는 항목만 수록했다.
- 최종 전체 테스트 364 통과/1 건너뛰기, 390px 및 1440px 흐름 확인. 운영 저장·배포와 PDF 재출력은 수행하지 않았다.

- 구현 커밋 `cb2c3b5`, [PR #154](https://github.com/Jamiewsm/ER-Website/pull/154) 생성. test 트랙 단독이며 merge와 운영 배포는 아직 하지 않았다.
- 주관식 CSS 삭제 후 후보 제목 스타일이 다른 규칙과 합쳐지지 않도록 기존 제목 규칙을 보존했다. 결과지 관련 32개 테스트를 마지막으로 다시 통과했다.
