# 프리미엄 검사 한국어 재검토

## 범위와 목적
배포 후 사용자 피드백에 따라 단어 검사의 의미 중복을 줄이고, 한국어 문항·안내·결과지의 번역투와 불명확한 표현을 다듬는다. 경험 기록과 실험 결과의 자유 의견 입력란을 제거한다. Track: test. 최신 origin/main에서 분리한 작업 디렉터리를 사용한다.

## 진행
1. 운영 페이지와 실제 연결된 문항·결과 콘텐츠를 읽고 중복 및 표현 수정 목록을 작성한다.
2. 단어는 유형별 9개, 총 81개로 줄인다. 점수 비교의 균형을 유지하고 질문·세션 버전을 올려 이전 117개 응답과 혼합되지 않게 한다.
3. 한국어 문구를 구체적이고 자연스럽게 수정한다. 유형별 동기 차이와 채점 방향은 유지한다.
4. 주관식 UI·세션 복원·결과 표시·신규 전송을 제거한다. 기존 저장 기록과 DB 구조는 보존한다.
5. 채점·버전·주관식 제거 회귀 검사, 전체 테스트, 실제 모바일/데스크톱 흐름 확인 후 커밋과 PR을 만든다.

## 완료 기준
81개 단어의 균등 배분과 중복 제거, 이전 응답 복원 차단, 주관식 기록의 신규 수집/전송 없음, 어색한 한국어 수정 목록, 선택형부터 결과까지 정상 동작이 확인되어야 한다. PR과 운영 반영 상태는 구분한다.
