# ER 검색 발견 기반과 콘텐츠 프로젝트

## 목적과 범위

기독교·성경적 에니어그램을 찾는 사람이 ER의 관점, 활용 범위, 교육과정을 읽고 다음 행동으로 이동하게 한다. Track은 site. 현재 공개 콘텐츠를 재사용하고 새 프레임워크나 CMS는 추가하지 않는다.

## 실행 순서

1. 운영 응답, 저장소, 검색 등록 상태를 감사한다. HTTP 응답과 관리 화면 증거를 구분한다.
2. 고유 title/description/canonical 및 읽을 수 있는 HTML 본문을 갖춘 기독교 에니어그램 핵심 안내와 성경적 관점 안내를 만든다. 개념 입문과 신학적 기준은 서로 다른 질문에 답한다.
3. 홈·기본과정과 안내 페이지를 실제 href 링크로 연결하고 sitemap 및 배포 경로를 반영한다.
4. 정적 문서 계약, 내부 링크, 배포 트랙 테스트와 데스크톱·모바일 브라우저 동선을 검증한다.
5. 커밋·push·PR을 작성한다. 저장소 역할에 따라 merge는 Cursor Cloud 메인, production deploy는 CI가 담당한다.

## 다음 단계

유형별 원고와 12주 콘텐츠 일정은 roadmap에 정리한다. 독립 유형 페이지는 충분한 원고와 실제 검색 질문이 확보된 순서로 추가한다. 검색 등록, 색인, 노출과 클릭은 각각 측정하며 검색 순위를 보장하지 않는다. 반복 발행이나 기관 연락은 이번 코드 구현으로 자동 실행되지 않는다.
