| 상태 | 대표 URL | 검색 질문 | 다음 행동 |
|---|---|---|---|
| 이번 구현 | / | ER은 어떤 기관인가 | 핵심 안내·교육과정 |

| 다음 콘텐츠 묶음 | /enneagram-types/ | 아홉 유형은 어떻게 다른가 | 유형별 설명 |

`enneagram-christianity`나 `enneagram-bible`처럼 같은 질문의 문서를 추가로 만들기보다 이미 있는 안내의 내용을 보완한다. 실제 발급 체계가 확인되기 전에는 자격증 페이지나 자격 효력을 주장하는 문구를 만들지 않는다.

유형 번호 순서보다 원자료의 완성도와 검색 질문에 대한 답의 품질을 우선한다. 원고가 부족하면 발행을 줄이고 기존 글을 보완한다.

## 원고마다 지킬 기준

- 첫 문단에서 독자가 가진 질문에 답한다. 검색어를 반복하기 위해 문장을 늘리지 않는다.
- 유형의 특징, 핵심 동기, 차이를 드러내는 상황, 오해, 관찰 질문, 관계에서의 실천을 다룬다.
- 공개용 문안을 원자료와 대조하되 내부 교재 전문·편집 규칙·AI 지침은 올리지 않는다.
- 유형과 고착을 구분하고, 유형을 정체성·영적 수준·소명의 최종 판정으로 사용하지 않는다.
- 사례는 실제 수강생 인용처럼 꾸미지 않는다. 실제 후기는 공개 사용이 확인된 자료만 쓴다.
- 단일 대표 URL, 고유 제목·설명, 실제 본문, 관련 페이지 링크와 하나의 교육과정 진입점을 확인한다.

## 등록과 유통

Google은 기존 도메인 속성에서 동일 sitemap URL을 관리한다. 배포 전 새 URL에 색인 요청하지 않는다.

Naver는 https://er-coaching.com 소유 확인 후 sitemap.xml을 제출하고 수집·색인 결과를 기록한다. 피드가 없는 현재 사이트에 빈 RSS를 만들지 않는다. 글을 정기적으로 발행할 때 실제 발행 콘텐츠에서 RSS를 만들 필요를 다시 판단한다.

Daum 등록 문안 초안.

- 사이트명. ER 에니어그램.
- 대표 주소. https://er-coaching.com/.
- 설명. 성경적 인간 이해를 바탕으로 기독교 에니어그램 교육과 코칭을 제공합니다. 기본과정과 1:1 멘토링을 안내합니다.
- 담당자·이메일. 사용자 확인 후 입력. 현재 제안은 공개 대표자명 손지영과 hello@er-coaching.com.

Naver 블로그에는 원문을 그대로 복제하기보다 핵심 질문 하나를 짧게 다루고 관련 ER 원문으로 연결한다. 게시 계정과 원고를 정한 뒤 별도로 발행한다. 기관 페이지의 링크는 실제 협력·강의 관계가 있을 때 요청한다. 이번 작업에서 외부 게시나 기관 연락은 실행하지 않았다.

## 측정

주 1회 수동 확인으로 시작한다. 노출수, 클릭수, CTR, 평균 게재순위는 Google에서 동일 기간·검색어·페이지 기준으로 비교한다. Naver의 수집·색인과 노출 자료도 별도로 기록한다. 사이트맵 접수, 발견, 색인, 검색 노출은 각각 다른 상태다.

기준일 현재 Google 개요 클릭 0, 홈페이지 색인 확인, sitemap 발견 URL 6. 실제 검색 순위·신청 전환 수의 기준값은 아직 수집하지 않았다. 신청 전환을 측정하려면 개인정보를 담지 않는 유입 경로 기록 범위를 먼저 정한다.
