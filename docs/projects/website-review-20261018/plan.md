# ER 웹사이트 리뷰 계획

- 목적. 공개 ER 웹사이트의 디자인·기능·효율성·사용성을 평가하고 실행 가능한 개선 순서를 제안한다.
- 범위. https://er-coaching.com 의 공개 화면과 주요 사용자 진입 경로, 관련 소스 구조. 운영 데이터 수정·실제 신청 제출·배포는 포함하지 않는다.
- 방법. 운영 화면을 데스크톱과 모바일에서 확인하고, 독립적인 소스 검토로 원인과 유지보수 비용을 확인한다.
- 검증. 주요 탐색, 새로고침/뒤로가기, 문의/신청 진입, 키보드와 모바일 레이아웃, 네트워크·콘솔, 관련 로컬 검사를 확인한다.
- 산출물. 근거와 심각도, 장점, 영역별 평가, 단계별 발전 제안을 포함한 review.md.

1. 현재 파일·디자인 지침·작업 상태 확인.
2. 실제 화면과 공개 흐름 확인, 소스 검토 병행.
3. 확인된 결함과 설계 제안을 구분해 우선순위 결정.
4. 리뷰 및 검증 한계 기록, 문서만 논리적 단위로 커밋.
