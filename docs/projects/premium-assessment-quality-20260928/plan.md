# 프리미엄 검사 평가·개선 기반 구현 계획

사용자가 2026-09-28 승인한 검사 발전 제안을 구현한다. 3센터·9유형은 유형, 자본·성본·사본은 하위유형으로 표현하며 날개와 구분한다. 공개 검사는 선택형을 유지한다.

1. 응답 안내와 후보 재검토를 구현한다. 여러 상황에서 반복되는 평소 반응을 안내하고, 초기 단어 후보를 확인·수정할 수 있게 한다. 초기 후보와 사용자 수정은 별도 보존한다.
2. 하위유형 근거와 일반 관심 영역 응답의 불일치, 미측정 상태, 세부 문항의 근거량을 정확하게 표시한다. 확률·정답률로 과장하지 않는다. 미확정 결과를 유지한다.
3. 선택형 고객 평가를 결과 화면에 제공한다. 체감 일치도 1–5와 판단 보류, 맞는/다른 부분, 질문의 어려움을 구분한다. 명시 동의·제출·실패 재시도·중복 처리를 갖춘 저장 경로를 연결한다.
4. 검사 시도와 문항·안내·채점·결과·평가 버전을 기록한다. 기존 실명 실험 데이터와 공개 고객 피드백의 목적·출처를 구분한다. 분석기는 버전·출처별 일치와 후보 포함을 계산하고 무자료를 0%로 오해하지 않게 한다.
5. 단어/문장 비교 실험의 고정 조건·지표·채택 기준 및 문항 검토표를 제공한다. 사용자를 모집하거나 연구 참여·자동 실험 배정을 시작하지 않는다. 검증되지 않은 문항으로 운영 전체를 교체하지 않는다.
6. 실제 브라우저의 모바일·데스크톱 흐름과 관련 테스트, 배포 범위 가드를 확인하고 의미 단위로 커밋한다. test 및 필요한 supabase 변경은 별도 PR로 만든다.

## UI 방향

기존 Restoration Green 토큰과 Pretendard/SUIT를 사용한다. 안내는 짧은 본문과 펼쳐보는 기준 설명으로 구성하고, 평가에는 의미 있는 라디오·체크박스와 충분한 터치 영역을 둔다. 결과·상담 링크를 평가 제출로 잠그지 않는다. 장식적인 통계와 추가 애니메이션은 쓰지 않는다.

## 완료 판정

- 평소 기준·상황 기준이 충돌하지 않고 한글·영문에서 작동한다.
- 단어 후보 밖 유형을 재검토할 수 있고 기존 응답·최초 결과 추적이 남는다.
- 본능 관련 응답 충돌 및 미측정 스트레스가 실제 측정값으로 표시되지 않는다.
- 선택형 평가의 저장 성공·실패가 실제 응답에 따라 표시되고 중복 제출과 잘못된 값이 차단된다.
- 기존 실명 실험과 새 피드백의 평가 출처가 보존된다. 상담 자기보고를 독립 정답으로 취급하지 않는다.
- 일반 사용자에게 미승인 연구 배정·외부 AI 전송을 시작하지 않는다.
- 관련 자동 테스트·전체 회귀·브라우저 QA·PR 상태를 구분해 보고한다.
