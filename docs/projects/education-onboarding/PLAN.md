# 등록 안내와 수업 전 준비

결제 확인·등록 확정은 수석코치가 결정한다. 수석코치가 포털에서 별도 보내기 버튼을 눌렀을 때만 등록 안내 메일을 발송한다. 메일은 과정/반/마감일과 내 교실 시작 방법을 짧게 안내하며, 강의계획안과 자기관찰보고서의 원본·작성·제출 상태는 교육포털에 모은다.

확정된 신청과 반 자리를 먼저 연결하고, 수강생이 같은 이메일로 가입·인증·로그인하면 기존 교실에 자동 배정한다. 기존 계정은 같은 경로로 바로 연결한다. 과거 8회차는 그대로 유지하며 사전 준비는 별도 kind와 position0으로 표시한다. 기존 과제/비공개 첨부 저장을 재사용한다.

미제출 알림은 마감 3일 전과 전날에 최대 두 번, 등록 메일 이후 최소24시간과 알림 간 최소24시간을 두고 보낸다. 발송 직전 제출/외부접수/취소/등록해제/기수종료를 다시 확인한다. 영속 선점·완료 기록으로 중복과 불확실한 재시도를 막는다. 자동화는 기존 GitHub Actions의 일일 작업과 기존 Resend를 사용하고 운영 활성화는 별도 배포 설정으로 남긴다.

범위는 포털 후속 PR #22와 별도 ER-Website supabase PR이다. 실제 운영 등록·이메일·파일 업로드·스케줄 활성화·merge·배포는 수행하지 않는다. 단위/DB 권한/브라우저 회귀 및 배포 묶음을 검증한 뒤 전달한다.
