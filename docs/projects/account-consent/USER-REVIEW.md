교육 기록은 이름·계정 이메일·반 배정·과제와 피드백 등 실제 서비스 항목에 맞춰 안내한다. 기존 기록을 광고에 사용하거나 고객 66명을 자동으로 수신 동의 상태로 전환하지 않는다.

인증 이메일 공급자와 해외 처리·위탁 정보는 기술 설정을 추가 확인해 원문에 기재한다. 사용자에게 확인되지 않은 업체나 기간을 선택하게 하지 않는다.

보관 기간과 탈퇴 정책이 정해지면 DB의 현재 계정 삭제 연쇄 처리와 일치하는지 먼저 검증한다. 탈퇴 후에도 증거를 보관하기로 한다면 현재 cascade 삭제 설계를 먼저 수정해야 한다. 확정된 원문과 함께 DB·포털을 적용하고 실제 가입·철회까지 확인한다.
