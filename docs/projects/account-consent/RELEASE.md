# 실제 적용 전 확인 사항

현재 구현은 운영 미적용이다. 기존 PR #53은 화면·기록 설계 참고용 draft로 유지한다. 신청 기능을 포함한 실제 코드 PR은 ER-Website #165와 CoachPortal-WebApp #56이다.

## 공개 문서

`er_consent_documents`에는 승인된 전체 원문만 service role로 추가한다. 문서가 없으면 신규 회원 완료를 허용하지 않는다. 가입용 문서 여섯 개의 purpose는 다음과 같다.

| purpose | 문서 역할 | 회원 행동 |
| --- | --- | --- |
| policy_notice | 개인정보 처리방침 안내 | 확인 |
| terms_acceptance | ER 이용약관 | 수락 |
| privacy_required | 가입·교육 서비스 개인정보 수집이용 | 동의 |
| news_email | 뉴스 이메일 안내·광고 목적 | 선택 동의 또는 거절 |
| events_email | 행사·프로그램 이메일 안내·광고 목적 | 선택 동의 또는 거절 |
| kakao_messages | 뉴스·행사 카카오 안내·광고 목적 | 선택 동의 또는 거절 |

각 문서는 `{purpose,title,body}` 형식이다. 승인자, 승인일, 시행일, 버전을 지정하며 서버가 전체 카탈로그와 개별 문서의 SHA-256을 계산한다. 원문 수정은 허용하지 않는다. 변경은 새 버전을 추가하고 다시 명시적으로 동의를 받는다. 테스트의 `synthetic-test-only` 문서는 공개할 수 없다.

## 확정한 운영 정보와 남은 적용 조건

- 사용자가 승인한 운영자 정보는 에니어그램 포 레스토레이션, 대표 손지영, hello@er-coaching.com이다.
- 교육 기록은 수료 후 1년이며 로컬 복사본에도 동일하게 적용한다. 동의 최소 증거는 철회·탈퇴 후 5년의 운영 기준이며 법정 공통 의무라고 안내하지 않는다.
- 사용자가 인증 메일도 기존 Resend로 연결하도록 승인했다. 현재 SMTP 설정은 비어 있으므로 기존 키를 Supabase SMTP 화면에 직접 입력한 뒤 실제 발송을 검증해야 한다.
- 공개용 여섯 문서의 원문은 `APPROVED-DOCUMENTS.json`에 기록했다. 이메일 연결과 백업 조건 충족 후 서버 문서 카탈로그에 추가한다.

현재 확인된 Supabase 프로젝트 리전은 미국 Ohio이다. 교육 안내 메일은 Resend를 사용한다. Auth는 아직 기본 SMTP 상태이며 Resend 연결 승인만 받은 상태다. 고객 66건, 카카오 친구 관계, 카카오 로그인 권한을 수신 동의로 이관하지 않는다.

## 배포 순서

1. 운영 문구 승인과 원문 버전 확정.
2. 전체 DB·Storage 백업과 복원을 검증하고 신청·계정 동의·동의 증거 만료 스케줄 migration을 적용한다. Auth 계정 이관 중 새 가입 누락을 막기 위해 migration이 Auth 쓰기를 잠시 잠근다. pg_cron은 매일 03:17 KST 만료된 목적만 파기한다.
3. 승인 문서 원문 추가 후 익명 catalog 조회와 기존 회원 상태를 확인. 신규 테스트 가입은 운영 동의서와 함께 수행한다.
4. 승인된 코드 병합·정적 포털 배포. 포털은 수동 `Deploy Pages`의 정확한 main SHA 확인이 필요하다. 코드 PR CI 통과만으로 운영 배포로 기록하지 않는다.
5. 이메일 가입·이메일 인증·소셜 인증 후 동의 완료·신청·승인·수신 철회를 운영에서 확인한다.

문서 없이 migration만 적용하면 기존 회원 접근은 유지되지만 신규 가입 완료는 중단된다. 이 상태로 서비스를 활성화하지 않는다. 실패 시 증거 테이블을 삭제하거나 과거 동의를 만들어 복구하지 않는다. 신규 가입을 보류하고 서버 상태·카탈로그·배포 버전을 확인한다.

## 운영 경계

가입 완료는 `er_memberships` 서버 상태로 판단한다. 이메일 회원은 동의 제출과 Auth 생성이 같은 트랜잭션이고, 소셜 회원은 인증 계정 생성 후 필수 동의를 거쳐 ER 회원 등록을 완료한다. 이메일 인증은 별도로 요구한다. 기존 회원의 `legacy` 상태는 서비스 접근 보존을 뜻하며 동의 증거가 아니다.

선택 수신 철회는 회원 탈퇴가 아니다. 문서가 변경되거나 현재 공개 문서가 없어도 기존 선택 동의는 원래 버전에 대해 철회할 수 있다. 개인정보 처리 전체에 대한 권리 요청·회원 탈퇴 처리는 승인 문서의 운영 연락처와 절차로 안내해야 한다.

`er_email_recipients('news_email'|'events_email')`는 service role 전용 발송 직전 대상 조회다. 카카오 채널 연결·친구 관계·발송 가능 ID는 확인하지 않으며 실제 메시지 발송이나 마케팅 자동화를 시작하지 않는다. 교육 승인·수업 알림과 마케팅 수신 설정은 별개다.

테이블의 직접 쓰기·공개 조회를 허용하지 않는다. 동의 기록은 본인 전용 RPC로 최근 100건과 현재 상태를 조회한다. 신규 회원은 동의 완료 전 교육·코치 RLS, 교육 권한 함수·수강 신청·기존 등록 연결·수석 검증이 제한된다. 코치 주소로 직접 들어와도 가입 동의 화면으로 이동한다. 기존 계정 UUID와 리포트 임시 저장은 보존한다.
