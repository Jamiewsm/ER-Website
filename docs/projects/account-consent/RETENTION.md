# ER 기록 보관·로컬 다운로드 운영 기준

2026-10-05 운영자가 모든 확인 항목을 승인했고 교육 기록은 1년, 로컬 다운로드, 동의 증거는 시장 기준 적용을 요청했다. 문의 담당은 에니어그램 포 레스토레이션 대표 손지영, hello@er-coaching.com이다.

| 회원 기본정보 | 회원 유지 중 | 탈퇴 요청을 확인한 후 삭제. 법령에 따라 별도 보존할 거래 자료는 구분 |
| 과제·공유 피드백·멘토링·교육 출석 | 실제 수료일 후 1년 | 학기 종료 시 실제 수료일 확인. 만료 자료는 백업·대상 확인 후 파기 |

5년은 모든 사업자에게 동일하게 적용되는 법정 의무라는 주장이 아니다. 광고성 정보 분쟁 대응을 위해 과태료 제척기간을 고려한 ER의 운영 기준이다. 처리방침·수집이용 동의에 목적·항목·기간을 명시한다. 재동의한 목적은 이용 중으로 전환하며 다른 목적의 만료일은 바꾸지 않는다.

근거를 확인한 자료는 [KISA 2026 개정 안내](https://www.kisa.kr/402/form?lang_type=KO&page=&postSeq=2577)와 [질서위반행위규제법 제19조 관련 공식 해석](https://www.law.go.kr/LSW/cgmExpcInfoP.do?cgmExpcDatSeq=480276&mode=2&ofiClsCd=350115)이다. 선택 항목에는 광고성 정보임을 명확히 표시한다. 수신 철회는 즉시 발송 대상에서 제외하며 증거 보관은 발송 권한이 아니다. 광고 발송을 시작할 때는 2년마다 수신 동의 확인 안내를 운영한다.

## 교육 기록 만료 처리

교육 기록을 만료 시 자동 일괄 삭제하지 않는다. 기존 `docs/operations/SEMESTER-ARCHIVE.md` 절차에 따라 대상·연결·파일·복원을 확인하고 사람 승인 후 삭제한다. 교육포털의 `edu_*` 자료는 코치 보고서 백업만으로 보존된 것으로 간주하지 않는다. 실제 수료일을 기록하고 매월 보관 만료 대상을 확인해야 한다. 현재 공개 DB에 완료 처리된 cohort는 없으며 계획된 `ends_on`을 실제 수료일로 추정하지 않는다.

학생의 내 기록 다운로드는 본인 수강·답변·공유 피드백·출석 JSON이다. 첨부 원본은 별도 다운로드하며 JSON을 전체 DB·Storage 백업으로 간주하지 않는다. 비공개 멘토 피드백과 다른 학생 자료는 포함하지 않는다.

## 동의 증거 만료 처리

2026-10-05 네 개 migration을 운영에 적용했다. `edu_cohorts.completed_at`은 최초 실제 수료일을 보존하며 이전 completed 기록의 날짜가 없으면 임의로 오늘을 넣지 않는다. `edu_record_retention_due()`로 수석이 만료·수료일 누락 대상을 확인한다. 수료 후 1년이 지난 원문·첨부는 학생·멘토 RLS에서 제한되며 물리 삭제는 기존 백업·승인 절차를 따른다. 동의 증거의 cron 작업 `er-consent-retention`이 `17 18 * * *`로 활성화된 것을 확인했다. 최초 실행 결과는 별도로 확인해야 한다.

`er_purge_expired_consent()`는 클라이언트 날짜를 받지 않고 서버 현재 시각으로 만료 목적만 파기한다. 계정 삭제 시 증거를 cascade 삭제하지 않으며 새 5년 만료 시각을 기록한다. 원문 문서에는 개인정보가 없으며 버전 검증을 위해 보존한다. 매일 03:17 KST 실행하는 pg_cron migration을 별도 적용하고, 적용 후 job 존재·실행 성공·실패 이력을 확인한다. 미적용 migration을 실행 중인 운영 작업으로 보고하지 않는다.
