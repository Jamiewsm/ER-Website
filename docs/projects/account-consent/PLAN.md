# ER 가입 동의 연동 계획

신규 ER 계정은 필수 개인정보 안내·수집이용 동의·이용약관 수락 후 회원 등록을 완료한다. 이메일 가입은 제출한 동의와 계정 생성이 함께 저장되고, 소셜 로그인은 인증 후 회원 등록을 완료한다. 기존 회원은 과거 동의를 추정하지 않고 기존 수업 접근을 유지한다.

뉴스 이메일, 행사 이메일, 카카오 안내는 각각 선택 항목이며 언제든 철회한다. 문서 버전·내용 해시·서버 시각을 불변 이벤트로 남긴다. 발송 자동화는 이 작업 범위에 포함하지 않는다.

운영 정보·보관 기간이 확정되기 전에는 문서를 공개하지 않는다. 미공개 상태에서도 기존 회원 접근과 선택 동의 철회는 가능해야 한다. PR #53은 설계 참고 자료이며 실제 구현은 신청 기능 PR #165와 #56에 연결한다.

검증은 격리 PostgreSQL에서 권한·원자성·중복·철회를 확인하고, 포털 테스트와 모바일 화면을 확인한다. 운영 DB 적용·배포는 별도 상태로 보고한다.

2026-10-05 사용자가 운영자·문의 주소·탈퇴 정책을 승인했다. 교육 기록은 수료 후 1년이며 로컬 복사본에도 같은 기간을 적용한다. 동의 증거는 철회·탈퇴 후 5년의 최소 기록 보관을 운영 기준으로 채택한다. 이는 업계 공통 법정 의무가 아니라 과태료 제척기간을 참고한 분쟁 대응 기준이다.

1. Auth 삭제 후 최소 증거 보존과 만료 파기를 구현·검증한다.
2. 승인 문서에 목적별 보관·철회 정보를 반영하고 광고성 정보 선택 항목을 명확히 한다.
3. 본인 교육 기록 다운로드를 제공하고 첨부 원본 백업은 별도 검증한다.
4. 실제 DB·Storage 백업·복원과 SMTP 연결을 확인한 뒤 DB·문서·포털 순으로 배포한다.
