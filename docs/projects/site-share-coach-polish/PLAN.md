# 사이트 공유·코치 소개 정리 계획

## 목표

- 링크 공유 시 브랜드 이미지가 선명한 대형 썸네일을 노출한다.
- 홈의 관계 카드 사진 프레임을 한 겹으로 단순화한다.
- 코치진 소개 명칭과 손지영 대표 약력을 최신 정보로 정리한다.

## 범위

- Track: `site`
- 대상: `index.html`, `js/sections/home.js`, `js/sections/coaches.js`, `js/strings.js`, `js/app-core.js`, 소셜 공유 이미지
- 제외: 진단 테스트와 Supabase 파일

## 검증

- 관련 정적 테스트와 전체 Node 테스트를 실행한다.
- 홈과 코치진 소개 화면을 데스크톱·모바일에서 확인한다.
- Open Graph 메타데이터와 이미지 크기를 확인한다.
