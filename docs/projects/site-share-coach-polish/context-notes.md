# 컨텍스트 노트

## 결정

- 대표 카드의 항목명은 `자격`보다 `약력`이 적합하다. 학력, 저서, 직책, 공인 자격이 함께 들어가기 때문이다.
- `대한민국 정부 인증 여성기업`은 개인 이력으로 섞지 않고 대표명 옆의 회사 신뢰 배지로 분리한다.
- 홈 관계 카드 사진은 외곽 카드와 사진 사이의 중첩 테두리·링을 제거하고 단일 프레임만 유지한다.
- 공유 썸네일은 작은 로고 파일 대신 1200×630 전용 브랜드 이미지를 사용한다.

## 검증 결과

- `node --test tests/*.test.mjs` 실행 결과 141개 테스트가 모두 통과했다.
- 데스크톱에서 홈 관계 카드와 코치진 소개 카드를 시각 확인했다.
- 모바일 390px 뷰포트에서 가로 넘침이 없음을 확인했다.
- Open Graph 이미지 URL과 1200×630 크기를 확인했다.
