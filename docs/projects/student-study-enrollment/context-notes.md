# 결정 기록

- Parenting 기존 식별자는 growth_201로 유지하고 신규 신청 표시명은 심화과정 102 Parenting 스터디로 제공한다.
- 신청은 received 상태로 시작한다. 결제 확인·등록 확정은 기존 수석코치 RPC에서 수행하며 자동 승인이나 학생의 enrollment INSERT를 허용하지 않는다.
- SECURITY DEFINER는 기존 관리자 전용 신청 테이블 접근에만 사용하며 인증 이메일·auth.uid를 서버에서 검증한다. anon 및 PUBLIC 실행권한은 회수한다.
- 기존 기본과정은 enrollment_open=false 기본값을 유지한다. 이번 두 스터디 기수만 허용한다.
- Parenting 기수 제목의 201 접두어만 102로 정정한다. 식별자·기수 키·등록 데이터는 보존한다.
- 기존 승인과 같은 기수 advisory lock을 사용하고 잠금 뒤 모집 상태를 다시 확인한다. 요청에는 이메일·권한·사용자 ID 매개변수가 없다.
- 운영 DB에는 아직 적용하지 않았다. API 먼저 적용하고 포털 화면을 배포한다.
