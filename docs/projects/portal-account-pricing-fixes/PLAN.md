# 사역자 할인 이메일과 교육 사진 권한

Track은 supabase다. 기본과정과 심화과정 모두 사역자 할인율은 사용자 확정 50%다. 기존 신청 message의 정확한 체크 줄을 서버에서 판별하고 기존 과정별 정가의 절반을 접수/결제 안내에 반영한다. 기존 정가·결제방법 문구가 모순되지 않게 공통 가격 계산을 사용하며 금액이 정의되지 않은 과정의 가격은 추정하지 않는다.

교육 사진은 기존 공개 coach-avatars 버킷의 본인 경로에 업로드한다. 기존 코치 정책을 보존하고 본인의 active/completed 교육 등록이 있는 학생/멘토/강사에게만 INSERT와 본인 파일 정리에 필요한 SELECT를 추가 허용한다. 클라이언트에서 고유 파일명/upsert:false를 사용하며 사진 URL 저장 실패 시 이번 신규 파일만 정리한다.

접수·결제 안내를 한 통으로 통합하되 등록 준비의 정원 예약과 결제 대기 처리는 유지한다. 이미 안내를 보낸 신청은 중복 발송하지 않는다. 사전 성찰은 자기관찰보고서로 이름을 바꾸고 사용자가 직접 제공한 강의계획안과 작성 안내를 메일 본문으로 함께 전달한다. 외부 설문 URL은 필수 조건에서 제거한다. 2026년 10월의 8회차 기준이며 과거 7–8월 일정은 복사하지 않는다.

실제 메일 발송·운영 Storage 업로드·운영 migration 적용은 실행하지 않는다. 계산/본문/권한 테스트와 정적 검토 후 PR로 전달하고 적용 순서와 미검증 범위를 기록한다. 포털 UI는 CoachPortal-WebApp의 별도 PR이다.

심화과정의 가격 정책은 사용자 확정 3개월 총 150,000원 또는 월 50,000원이다. 사역자는 50% 할인한다. 실제 성장 과정과 해당 기수의 연결을 검증한 신청에만 적용하며, 현재 미개설 기수나 별도 parenting_workshop 상품을 임의로 연결하지 않는다.

통합 안내는 발송 전 영속 시도 기록을 원자적으로 저장한다. 발송 완료 기록이 있으면 생략하고, 시도만 남아 결과가 불확실하면 운영 확인 전까지 자동 재발송하지 않는다. 짧은 provider idempotency 기간이 지나도 중복 방지를 유지한다.
