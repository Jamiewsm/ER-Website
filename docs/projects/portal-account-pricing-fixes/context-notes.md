# 맥락과 결정

- 사용자 요청은 사역자 체크에 따른 할인 메일, 교육 사진 업로드, 중복 접수/확인 메일 통합, 자기관찰보고서와 강의계획안의 전문적인 안내다.
- 사용자가 기본·심화 모두 할인율 50%라고 확정했다. 기본 정가 450,000원/US$330은 할인 후 225,000원/US$165다. 심화는 3개월 총 150,000원 또는 월 50,000원이며 할인 후 총 75,000원 또는 월 25,000원이다. 심화 USD는 추정하지 않는다.
- 신청 체크값은 message의 정확한 줄 `전임 사역자 및 사모: 해당`으로 저장된다. 기존 저장 계약을 서버에서 읽어 과거 신청의 등록 준비에도 동일 계산을 적용한다.
- 접수·결제 안내를 한 통으로 통합한다. 등록 준비 RPC는 정원 예약과 결제 대기 처리를 유지하고 이미 보낸 메일만 생략한다. 초기와 복구 안내는 같은 템플릿과 provider key를 사용한다.
- 독립 검토에서 발송 성공 후 기록 저장 실패와 24시간 경과가 겹치면 provider key만으로 중복을 막지 못하는 문제를 확인했다. 발송 전 조건부 UPDATE로 시도 기록을 영속 저장하고, 결과가 불확실하면 자동 재발송을 차단한다. 운영자가 실제 발송 내역을 확인한 뒤 복구한다.
- 사용자가 질문지 주소 미설정으로 보인다고 확인하고 Syllabus와 자기관찰보고서 원문을 제공했다. 폼 URL 대신 내용을 메일 본문에 담는다. 내부 pre_survey 이벤트/발송 컬럼은 호환을 위해 유지하고 표시명은 자기관찰보고서·강의계획안으로 바꾼다.
- 원문의 Summer/7–8월 날짜는 2026년 10월 개강과 8회차별 주제로 정리했다. 정확한 수업 날짜는 추정하지 않는다. 사용자 제공 강사 경력과 참고 자료를 보존했고 보고서는 A4 1장 내외 자유 서술, 선택 질문 8개, 강사 이메일 제출로 안내한다.
- 별도 PDF 강의계획안 2쪽과 DOCX/PDF 자기관찰보고서 2쪽을 생성하고 한글·표·페이지 끝을 시각 확인했다. 보고서 부제의 기본 기울임 상속을 제거하고 최종 정자체 표시를 확인했다. 이메일은 640/390/320px 넘침 없이 확인했다.
- 교육 아바타는 클릭 이벤트가 없고 기존 coach-avatars INSERT/coach_sync_my_avatar는 활성 코치 전용이었다. 새 버킷을 만들지 않고 active/completed 교육 등록자의 본인 경로에 INSERT/SELECT를 허용한다. 기존 코치/삭제 정책은 보존한다.
- 웹 폼과 실제 renderApply 실행을 조사한 결과 성장 과정 전용 신청 폼은 없고 운영 성장 기수·반도 없다. 따라서 이번 심화 작업은 가격 정책 준비이며 실제 모집 개설이 아니다. 공개 parenting_workshop은 별도 4주/$120 상품이므로 3개월 과정으로 바꾸지 않는다.
- canonical ER-Website의 site/search-console-sitemap 작업은 건드리지 않았다. origin/main aa10703에서 supabase/ministry-discount-profile을 별도 worktree로 만들었다. 포털 UI와 본사이트의 오래된 안내 문구는 각 저장소/track의 별도 PR로 전달한다. 기존 열린 PR #129, #123, #90은 수정하지 않는다.
- DEPLOY_LEDGER는 오래된 기록이므로 이번 코드·정책 수정의 운영 적용 근거로 삼지 않는다. 운영 DB/Storage 쓰기·이메일 발송·merge·배포는 실행하지 않는다.
