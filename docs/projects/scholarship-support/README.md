# 장학 후원 계좌 안내

Track: site. 공개 페이지는 `/#support`다.

2026-09-21 사용자 요청에 따라 후원 페이지를 계좌 안내로 간소화했다. 간증, 장학 목적과 누적 수강료 감면 실적, 빨간 하트 메뉴는 유지한다.

## 페이지 구성

추가 피드백에 따라 “사역자를 돌보는 일이 공동체를 돌보는 일이 되도록”을 첫 제목으로 사용한다. 사역자의 필요 → 배움으로 열리는 자리 → 장학 지원 안내 → ER의 간증 → 사용 목적과 일시후원 계좌 → FAQ → 한 사람의 회복을 위한 초대 순서다. 세 곳의 주요 CTA는 모두 같은 계좌 안내로 이동하고 키보드 포커스도 함께 옮긴다.

지원 범위는 운영자가 확인한 기본과정·심화과정·코치트레이닝의 사역자 반액 장학이다. 피드백 예시의 무료 코칭·선정 심사·금액별 지원 효과는 적용하지 않는다. 90명 이상·약 1,100만 원은 누적 수강료 감면이며, 수령한 후원금 총액으로 표시하지 않는다. 공개 동의를 받은 참여자 후기는 아직 제공되지 않아 후기 섹션을 만들지 않는다. 별도 장부 운영이나 정기 보고 주기도 확인 없이 약속하지 않는다.

대표 이미지는 기존 `assets/er-visual/hero-home.jpg`를 재사용하며 실제 참여자의 모습이나 ER의 코칭 공간이라고 표시하지 않는다. 장학 문의는 이메일을 사용해 별도의 무료 코칭 신청 흐름과 혼동하지 않도록 한다.

입금처의 단일 출처는 `js/config.js`의 `window.ER_SCHOLARSHIP_SUPPORT`다. 사용자에게 받은 공개 수취 정보만 저장한다.

## 동작 범위

금액 입력, 일시·정기후원 선택, 앱 선택, 송금 안내 단계, 입금 확인 요청서, 온라인 접수 API 연결을 제거했다. 페이지는 개인정보를 수집하거나 결제·자동이체·입금 확인을 처리하지 않는다. 은행 및 송금 서비스의 실제 거래 내역은 운영자가 확인한다.

이전에 공유한 `/#apply?track=support` 및 송금 확인 요청 링크는 이메일 문의 안내를 보여준다. 과거 후원 접수 완료 hash도 접수 성공을 표시하지 않고 문의 안내로 연결한다. 기존 과정 신청 기능은 유지한다.

후원 전용 접수 메일 PR #146은 이 정적 계좌 안내에 필요하지 않다. Supabase 변경이나 추가 서비스 없이 site track으로 배포한다.

## 검증

`node --test tests/scholarship-support.test.mjs`에서 계좌 노출, 제거한 온라인 접수 기능의 부재, 기존 후원 링크 처리, 출력 escaping을 확인한다. 모바일·데스크톱에서 계좌번호와 예금주가 읽기 좋게 표시되는지 검토한다.
