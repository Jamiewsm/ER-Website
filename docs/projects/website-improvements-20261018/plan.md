# 웹사이트 리뷰 개선 계획

## 목적과 범위

2026-10-18 리뷰의 R1–R10을 우선순위대로 개선한다. site 트랙 작업이며 진단 테스트 런타임·DB·실제 신청 데이터는 변경하지 않는다. 기존 정적 사이트 구조와 디자인을 유지한다.

1. 신청 URL을 통한 HTML 삽입을 실패하는 회귀 테스트로 고정하고, 허용값 검증 및 정적인 폼 제출 처리로 수정한다.
2. 개인정보 입력 안내, 키보드 메뉴, 작은 화면의 보안 위젯을 보완한다.
3. 이미지·CSS·필요한 기능 로딩을 개선하고 공지 갱신에 따른 화면 초기화를 막는다.
4. 버튼/정책 문구·근거 미표시 수치·페이지 제목을 정리한다.
5. 관련 검사와 전체 사용 가능한 검사를 실행하고, 로컬 실제 브라우저에서 정상/조작 URL, 키보드,320/390/1440px 화면과 주요 흐름을 확인한다.

운영 반영은 레포의 최신 main·CI·배포 트랙 지침을 따른다. 실제 신청/메일 발송은 검증 과정에서 수행하지 않는다. 사람 대상 사용성 실험과 검색 수요 조사에 의존하는 독립 URL 확장은 구현 범위에서 제외한다.
