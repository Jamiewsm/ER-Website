부모 관찰형

우리 아이 유형 관찰 테스트

아이의 반복되는 행동과 정서 반응을 관찰해,
욕구와 두려움을 이해하는 부모용 체크리스트입니다.

이 관찰지는 아이를 하나의 번호로 단정하기 위한 도구가 아닙니다. 결과는 진단이 아니라 유형 가설이며, 최종 해석은 대화·추가 관찰·전문가 상담으로 보완합니다.

작성 전 안내

  • 최소 1–2주 동안 여러 상황에서 관찰한 뒤 작성합니다.
  • 한두 가지 행동만으로 유형을 정하지 않습니다.
  • 아이가 “왜 그랬는지” 확실하지 않으면 0 · 관찰부족을 선택합니다.
  • 결과는 진단이 아니라 유형 가설입니다.
  • 최종 해석은 아이와의 대화, 추가 관찰, 전문가 상담으로 보완합니다.
소요 시간 약 10–15분 · 평소 아이의 모습을 떠올리며 관찰 문항과 비교 문항에 답해주세요.

메인으로 돌아가기

아직 응답하지 않은 문항이 있어요. 잘 모르겠으면 “0 · 관찰부족”을 선택해 주세요.
