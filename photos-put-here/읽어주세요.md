# 배경 사진 — 여기에 넣으세요

**이 폴더가 정본입니다.** VS Code에서 `ER-Website` 저장소를 연 다음, **맨 위(루트)에 있는 `photos-put-here` 폴더**를 여시면 됩니다.

```
ER-Website/                    ← GitHub에서 clone 한 폴더
├── photos-put-here/           ← ★ 지금 이 폴더 ★
│   ├── 읽어주세요.md
│   ├── hero-home.jpg          ← ① 홈·브로셔 표지·랜딩
│   ├── warm-hand.jpg          ← ② 브로셔 2페이지 (공감)
│   └── warm-candles.jpg       ← ③ 브로셔 4·5페이지
├── index.html
├── parents-brochure.html
└── ...
```

## 사진 바꾸는 방법

1. 아래 **파일 이름을 그대로 유지**한 채, 본인 사진으로 **덮어쓰기** (같은 이름의 JPG).
2. 저장 후 브라우저에서 사이트 새로고침 (캐시가 남으면 Ctrl+Shift+R).

| 파일명 | 어디에 쓰이나요 |
|--------|----------------|
| `hero-home.jpg` | 홈 첫 화면 톤, 모바일 브로셔 1·3·6페이지, 웹 랜딩 |
| `warm-hand.jpg` | 모바일 브로셔 2페이지 |
| `warm-candles.jpg` | 모바일 브로셔 4·5페이지 |

권장: 가로 1600px 이상, JPG, 따뜻한 크림·부드러운 빛 (홈 분위기와 비슷하게).

## 로컬에 이 폴더가 없을 때

터미널에서:

```bash
git clone https://github.com/Jamiewsm/ER-Website.git
cd ER-Website
git pull origin main
```

그다음 VS Code → **폴더 열기** → `ER-Website` 선택.

`photos-put-here` 가 보이지 않으면 `git pull origin main` 이 안 된 것입니다.

## (선택) 브로셔 인쇄용 복사본 갱신

인쇄/PDF용 `assets/parents-brochure/bg-*.jpg` 를 맞추려면 리포 루트에서:

```bash
bash scripts/sync-photos-to-brochure.sh
```

웹 화면은 **이 폴더만** 바꿔도 반영됩니다.
