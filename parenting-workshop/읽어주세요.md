# Parenting Workshop — 모바일 브로셔 PNG

VS Code에서 만든 **`parenting-workshop`** 폴더가 정본입니다. (폴더 이름에 공백이 있으면 `parenting-workshop` 로 맞추세요.)

## 넣을 파일 (파일명 그대로)

| 파일 | 페이지 |
|------|--------|
| `mb1.png` | 표지 |
| `mb2.png` | 공감 |
| `mb3.png` | ER 관점 |
| `mb4.png` | 프로그램 특징 |
| `mb5.png` | 4주 커리큘럼 |
| `mb6.png` | 신청 안내 (QR 영역은 웹에서 ER QR로 교체) |

권장 크기: **1080×1920** (9:16), PNG.

## 확인

1. 위 6개를 이 폴더에 넣고 저장
2. 로컬 서버 후 `/parents-brochure.html` 열기
3. 6페이지가 세로로 넘어가는지, 마지막 QR이 ER 것인지 확인

mb6 QR 위치가 어긋나면 `css/parents-brochure.css` 안 `--pb-qr-bottom`, `--pb-qr-width` 값을 조정하세요.
