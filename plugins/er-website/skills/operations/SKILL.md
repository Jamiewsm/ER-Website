# ER Website 운영

- 신청 상세 정보를 보기 전에 목록에서 실제 신청 ID를 확인한다.
- 상태 변경 전 현재 신청서와 목표 상태를 사용자에게 보여 주고 승인된 요청만 실행한다.
- 결제 확인, 등록 확정, 취소, 신청서 삭제, 이메일 발송은 이 도구에서 제공하지 않는다.
- 웹사이트 코드 변경은 기존 GitHub PR과 배포 절차를 따른다. 이 플러그인의 신청 관리 도구로 코드를 직접 변경하지 않는다.
- 신청자 개인정보는 처리에 필요한 최소한만 답변한다.
