# ER 코치포털 운영

- 먼저 `coach_profile`로 현재 계정과 활성 상태를 확인한다.
- 조회 결과는 로그인한 코치에게 허용된 범위로 이해한다. 다른 코치의 자료를 추측하지 않는다.
- 과제는 초안 상태로만 생성한다. 공개·배정이 필요하면 포털에서 검토한다.
- 학생·멘티의 민감한 기록을 대화에 불필요하게 복사하지 않는다.
- 운영 도구에 없는 자료 파일 업로드, 삭제, 코치 권한 변경은 가능한 것처럼 말하지 않는다.
